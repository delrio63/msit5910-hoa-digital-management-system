# MSIT 5910 – HOA Digital Management System

A capstone project for the University of the People MSIT program, demonstrating system design, secure architecture, version control best practices, and an initial implementation of a digital management and communication platform for small Homeowners Associations (HOAs).

---

## Project Overview

Small HOAs often rely on informal communication, scattered documents, and manual processes. This project proposes and demonstrates a lightweight digital management system that centralizes communication, document access, announcements, and basic administrative workflows.

The system is built using:

- Python  
- Streamlit (presentation layer)  
- Modular backend components  
- Secure architecture principles (RBAC, data boundaries, least privilege)  
- GitHub version control workflow  
- CI/CD tagging for release management  

This repository contains the working prototype developed for Unit 4: Initial Implementation and Demo Presentation.

## Security & Ethical Considerations

This project incorporates principles discussed in Unit 3:

- Role‑based access control (RBAC)  
- Data minimization  
- Secure boundaries between modules  
- Logging and auditability  
- Ethical handling of homeowner information  

These principles are reflected in the system architecture and module specifications.
